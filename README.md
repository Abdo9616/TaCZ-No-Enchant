A small Forge mod that blocks enchanted-book upgrades on TACZ guns in survival, while still allowing normal creative-mode use.

## What it does
- Prevents the standard anvil enchant-book flow for TACZ guns in survival.
- Works with both the normal slot order and the reversed slot order.
- Allows creative-mode players to enchant normally.
- Can optionally strip existing enchantments from TACZ guns when a player joins, if enabled.

> [!NOTE]
> TaCZ Guns do not accept enchantments in survival by design but, when combined with other mods like [TACZ: Durability](https://www.curseforge.com/minecraft/mc-mods/tacz-durability), players can use some enchantments which this mod is made to prevent this for who prefers.

## Config
The config is generated by Forge in the usual `config/` folder. The main option is:

```toml
stripExistingEnchantments = false
allowedGunIds = []
```

`stripExistingEnchantments` is disabled by default.

Warning: removing enchantments from a player's inventory is irreversible. It is intended for specific cases such as emergency cleanup, migration, or accidental enchantment recovery, and it is also meant to remove already-enchanted TACZ guns that players may have obtained through alternative methods or during brief enchant attempts that temporarily flash before being reset.

## Exempt gun IDs
If you want to allow a specific TACZ gun to ignore the restriction, add its GunId here:

```toml
allowedGunIds = ["tacz:ak47"]
```

Example:

```toml
allowedGunIds = ["tacz:ak47", "tacz:another_gun_id"]
```

This works in both singleplayer and multiplayer.

## Notes
- Normal survival players cannot use enchanted books on TACZ guns through the standard anvil route.
- Creative mode is exempt by design.
- The stripping option only runs on player join and only when enabled.
